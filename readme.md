# hypixel jacob contest bot

This is a discord bot that just sends notifications for specific contests and pings specific roles for that contest (that are generated automatically by this discord bot). It will have a few more features like weekly stats and what not, but not much because I don't know how to make bots (so if you want a feature added just open a PR or fork this repo - not that making this on your own if you know what and how to do wouldn't be hard)

This bot is semi actively hosted by me, I won't add a link to add the bot for now because I would have to set up everything as I want to (name, profile picture...) so maybe later (also if I will be hosting it and making the link public I'll host it permanently on my homelab - at least it will have more use)

## Data source

Thanks to incredible work of [Jan Straßburger](https://github.com/KartoffelChipss) and [Misjudgments](https://github.com/Misjudgments) I'm able to get Jacob contest data from their project [jacob-contests](https://github.com/KartoffelChipss/jacob-contests), specifically from theirs web for [Jacob's farming contest](https://jacobs.strassburger.dev) and theirs API endpoint.
